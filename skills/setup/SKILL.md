# Technical setup

Read the [setup guide](../../docs/pi-setup.md) and use the shipped [setup CLI](../../scripts/setup.py). Resolve links from this skill directory in the kit, not from the workspace. You can invoke this skill with `/skill:setup`.

Ask only for missing technical information: the personal workspace path and named local Git target mappings. Read accessible configuration first; reuse supplied facts. Do not start a business, identity, voice, or revenue interview. For ordinary setup, do not request a knowledge location or treat its absence as an A14 blocker. Personal Fathom is optional. Shared meeting notes are not established and remain deferred.

Inspect first. Present the exact local file plan and its findings. A trusted project APPEND_SYSTEM shadows rather than combines with user APPEND_SYSTEM. Preserving bytes does not preserve effective instructions. Obtain separate explicit approval to apply and explicit acknowledgement of this precedence; never infer either from a request to inspect or from invoking this skill. Do not merge or overwrite existing settings or instructions. Stop on conflicts, symlinks or a stale plan. Do not copy credentials, change trust, install software, or edit global settings.

Only for an explicit knowledge setup request, read the [knowledge guide](../../docs/knowledge-hub.md) and use the [knowledge CLI](../../scripts/knowledge.py). Ask only for the missing local checkout path if needed. Inspect and obtain separate explicit approval to create the workspace mapping. Keep the hub read-only: do not update the checkout, run source commands, or follow external links. An explicit PRD lookup returns an index of citations, not task context or approval; read the affected source before making a decision.

Distinguish observed local version/Git reads and Pi skill registration from working integrations. Report missing Pi and Herdr separately. The [standalone read-only ClickUp reader](../../docs/clickup.md) is available, but setup makes no ClickUp request and does not check authentication. Do not request a token in chat or run the reader as part of setup. The [selected-task preparation helper](../../docs/task-preparation.md) is available locally; setup does not perform a task assessment. OpenSpec drafting, live factory launch and provider fallback remain unsupported; registration is not readiness or permission to launch. Do not launch agents or worktrees, commit, push, clean up or publish. See the guide for NOT VERIFIED platform and authenticated boundaries.
